# My Skills

This repository is the home for my agent skills. Each folder under `skills/` is one skill I attach when I want an agent to write, review, or change code to that standard. The skill file is the instruction set; the examples next to it show the shapes to follow.

A skill is not a library and not a résumé line. It is a written rule for how code in that language should be cut, named, and tested.

## Skills in this repo

| Skill | Path | What it is for |
| --- | --- | --- |
| Flutter clean code | [`skills/flutter-clean-code`](skills/flutter-clean-code/SKILL.md) | Dart and Flutter: widgets paint, state decides, pure functions hold the rules. |
| Python clean code | [`skills/python-clean-code`](skills/python-clean-code/SKILL.md) | Python modules, packages, CLIs, and services: one responsibility, typed public APIs, failures as exceptions. |

## Layout of a skill

```
skills/<skill-name>/
  SKILL.md
  references/examples.md
```

- `SKILL.md` is the skill. The front matter names it and says when to use it. The body is the procedure.
- `references/examples.md` holds the shapes the skill points at. Read it before adding a new type, public function, or test.
